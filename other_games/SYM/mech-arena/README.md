# 🤖 MECH ARENA · 机甲对决

一款 2D 俯视角机甲对战网页游戏：**单机挑战 AI** 与 **本地双人对战** 双模式，
纯 HTML5 Canvas + 原生 JavaScript 实现，无任何外部依赖，程序化生成音效与霓虹风格战场。

![技术栈](https://img.shields.io/badge/HTML5-Canvas-blue) ![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow) ![Node.js](https://img.shields.io/badge/Node.js-静态服务器-green) ![零依赖](https://img.shields.io/badge/依赖-零-lightgrey)

---

## 🚀 快速开始

```bash
cd mech-arena
node server.js
```

浏览器打开 **http://localhost:3000** 即可游玩。

> 也可以直接双击 `index.html` 用浏览器打开（无需服务器）。

### 🤝 局域网对战（两台电脑真人对战）
- 主菜单 → 🌐 局域网对战：房主「创建房间」（自动显示房间号 + 本机 IP）→ 对手输入 IP 加入
- **房主权威同步**：房主完整模拟对局，20Hz 状态快照广播（位置/血量/子弹/道具全同步）
- 双方各自选择机甲/武器/插件，全流程局域网直连，延迟 <30ms
- 双方需在同一局域网并各自运行 `node server.js`；断开自动提示
- 服务器为纯 Node 实现的最小 WebSocket（RFC 6455，零依赖），支持粘包/掩码/分片重组/心跳
- **安全加固**：`GET /%`、NUL 字节路径返回 400（远程 DoS 修复）；JSON `null` 消息不误关连接；
  加入房间去重、观战者重连清理、聊天/昵称长度上限与截断；客户端聊天消息 XSS 转义、
  开局消息机甲白名单校验、快照数组防御、`tryLanStart` 幂等

### 👾 Boss 战模式
单人挑战巨型机甲（烈焰巨兽 3200 血 / 冰霜巨兽 2800 血，减伤 15%）：
- **三阶段**：Ⅰ 警戒（扫射/导弹）→ Ⅱ 狂怒（+蓄力炮/冲撞，技能加快）→ Ⅲ 灭世（狂暴 + 召唤小兵）
- 阶段切换全屏红闪 + 恢复 8% 护盾；击败后有 10 段连爆演出
- 结算按伤害/通关发奖，记录击败次数/最快时间/最高伤害，首次通关额外 +300

### 📊 战绩档案
主菜单「档案」页：总场次/胜率/总击杀/最高连杀/大招数/累计收入、各机甲使用场次（最爱底盘）、排位段位、生存最高波次、锦标赛冠军数、Boss 记录。

### ⚖ 平衡性（第二轮数值校准）
- 大招充能按**伤害比例**（不再按命中次数，机枪/狙击充能差距 15 倍 → 缩至 ~2 倍）
- 排位净零和 **+25/-25**，连胜加成封顶 +6（第 2 连胜起每胜 +3）
- 狙击 60 伤穿透 3、声波炮穿透 4、等离子 58 伤、毒针 DoT 10
- 商店：声波 700 / 特斯拉 850 / 燃烧榴弹 950 / 无人机 900 / 等离子 950

### 🏅 徽章系统（胜利获得，商店兑换）
- 每场胜利获得徽章（排位胜利额外 +1、锦标赛夺冠 +5、生存每 3 波 +1、Boss 击败 +3）
- 徽章商店兑换：金币袋（20）、经验结晶（50）、能量核心（80）、**机甲皮肤**（每底盘 3 款：120/150/200）
- 皮肤在机库中装备，战斗实时生效（机身配色 + 发光色）

### 💬 局域网联机扩展
- **聊天**：房间界面 + 战斗中 HUD 实时聊天（Enter 发送）
- **观战**：第三台电脑可加入房间观战（同步状态快照）
- **重赛**：房主结算界面点「再来一局」直接重开，无需重新建房

## ⚔ 战斗模式

### 🏅 排位赛
六段位体系（青铜 → 白银 → 黄金 → 白金 → 钻石 → 大师），起始 1000 分，下限 100 分。
胜利 +25 分、失败 -25 分；连胜加成（第 2 连胜起每胜 +3，封顶 +6）。段位越高 AI 越强（青铜/白银 → 简单，黄金 → 普通，白金+ → 困难）。
排位同样获得金币与经验，段位升降在结算面板实时提示。

### 🏆 锦标赛
8 人单败淘汰（八强 → 半决赛 → 决赛），7 名 AI 机师随机机甲出战，其余对局自动模拟。
连赢 3 场夺冠：+400 金币，奖杯数永久记录。中途出局可随时重开。

### 🎯 训练场
无奖励、无惩罚的自由练习。可选 AI 强度（木桩/简单/普通/困难）与 AI 机甲。
「木桩」是原地不动的靶子，适合练习走位与武器手感。

### 🤝 双人对战
同屏本地对战（P1 使用养成机甲，P2 使用基础属性，公平竞技）。
**娱乐模式：不获得金币/经验/徽章，不计入战绩场次**（防本地刷奖励）。

## 🛠 游戏系统

### 底盘 + 武器槽位系统
「机甲」升级为「底盘 + 多武器槽」的自由配置体系，**不同底盘槽位数量不同**：
- **磐石 · 重装**：3 槽（1 主 2 副）· 被动减伤 8% · 技能护盾 · 副槽弹药上限 20
- **疾风 · 轻型**：2 槽（1 主 1 副）· 被动加速 6% · 技能冲刺
- **猛禽 · 突击**：2 槽（**双主武器无限火力**）· 被动技能冷却 -12% · 技能 EMP
- **烈焰 · 炮手**：3 槽（2 主 1 副）· 被动增伤 8% · 技能湮灭炮
- **守护 · 支援**：3 槽（1 主 2 副）· 被动纳米再生（每 2.5s 回血）· 技能治疗波（回血+净化）· 大招圣盾领域（6s 持续回血+护盾）

槽位规则：主槽无限弹药（机枪过热机制），副槽共享弹药（弹药箱补充）。

## 🔧 代码审查与结构优化（本轮）

**审查方式**：3 个独立审查代理并行通读全部代码 + 实测验证，修复 30+ 隐藏问题：

**高危修复**：
- Boss 战「冰霜巨兽」三件套方法缺失（首帧崩溃，测试盲区掩盖）→ 恢复

- 榴弹"弹墙反弹"实际从未反弹 → 用上一帧位置判穿越方向
- 每日任务领取后可重复领取刷奖励 → `claimed` 状态机修复
- 存档 `ranked.score` 字符串/NaN 未清洗 → 拼接变大师 + 白拿成就 → sanitize 类型清洗
