## 0. 一句话定位

一款面向 PC 与移动端的**单人 3D 写实战术射击游戏**：扮演被困在虚构学院中的成年学员汪义轩，在被虚构武装势力占领的区域里**搜刮装备、与战术 AI 交火、伺机突围撤离**，体验硬核拟真、步步为营的生存压力。

> 内容边界（重要）：全部世界观、人物、组织、场景均为**原创虚构**，不对应任何现实学校或真实事件；角色均为成年人；核心是"战术生存与突围"，而非针对特定群体的无差别暴力。

## 2. 玩法流程

### 2.1 单局循环（Core Loop）

```
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│ 整备出击 │ → │ 潜入搜刮 │ → │ 遭遇交火 │ → │ 抵达撤离 │ → │ 结算成长 │
│ (局外)   │   │ (局内)   │   │ (局内)   │   │ (局内)   │   │ (局外)   │
└─────────┘   └─────────┘   └─────────┘   └─────────┘   └─────────┘
     ↑                                                          │
     └──────────────────── 带回战利品 / 装备损失 ─────────────────┘
```

1. **整备出击**：在仓库选择带入的武器、弹药、护甲、医疗品；可跑"轻装"（灵活、损失小）或"重装"（火力强、风险高）。
2. **潜入搜刮**：进入地图，搜索容器、房间、尸体获取物资；听声辨位判断威胁。
3. **遭遇交火**：与战术 AI 或敌对学员交火；利用掩体、部位伤害、护甲克制决胜负。
4. **抵达撤离**：在限定条件下到达撤离点（可能需要等待倒计时、激活信号、支付"通行物资"）。
5. **结算成长**：成功则带回全部战利品，失败则损失带入与拾取物资；积累货币与经验，解锁更好的装备。

### 2.2 单局时间线（建议）

| 阶段 | 时长 | 体验目标 |
|---|---|---|
| 进入与orientation | 0–2 分钟 | 熟悉出生点、判断方向、初期搜刮 |
| 中部搜刮与游走 | 2–10 分钟 | 资源积累、首次接触、信息博弈 |
| 高烈度交火 | 10–18 分钟 | 据点争夺、AI 围剿、撤退决策 |
| 撤离阶段 | 18–22 分钟 | 撤离点开放、最后冲刺、守卫拦截 |
| **单局总计** | **约 15–25 分钟** | 紧张但可完成，符合"平衡成长" |

### 2.3 胜负与损失规则

- **撤离成功**：带回背包内全部物资，获得经验与货币。
- **阵亡/未撤离**：损失带入装备与已拾取物资（可在设置中提供"保险箱"保留少量关键物品）。
- **超时**：撤离点关闭后滞留视为失败。
- **成长保护**：新手期前若干局提供"保底装备"，避免死亡螺旋（契合"平衡成长"）。

## 3. 系统模块

### 3.1 拟真射击与战斗系统（核心）
- **弹道**：子弹下坠、初速、有效射程；不同枪械弹道差异。
- **穿透与护甲**：弹药类型 × 护甲等级克制；穿甲后伤害衰减。
- **部位伤害**：头/胸/腹/四肢分区，不同部位伤害系数与致残效果（如腿部中弹减速）。
- **后坐力与操控**：垂直/水平后坐、压枪、腰射/机瞄/倍镜切换。
- **状态效果**：出血、疼痛、骨折等，需对应医疗品处理。
- **声音传播**：枪声、脚步按距离与障碍物衰减——同时是 AI "听声辨位"的输入。

### 3.2 搜刮与背包系统
- 网格化背包，物品占用不同格子体积，空间管理本身是玩法。
- 可搜刮对象：储物柜、课桌、箱体、自动贩卖机、敌人尸体。
- 搜刮有耗时与声音，制造"搜刮时的脆弱窗口"。
- 物资稀有度分层：常见 / 稀有 / 贵重。

### 3.3 装备与改装系统（高拟真）
- 武器可装配：枪口、枪管、握把、瞄具、弹匣、枪托等。
- 配件影响后坐、精度、射速、携行等数值。
- 护甲分级、头盔分级、防弹插板。
- 弹药类型管理（普通/穿甲/亚音速等）。

### 3.4 敌人 AI 系统（战术型高智能）
- **感知**：视觉（视锥、遮挡）、听觉（枪声/脚步）、受击反应。
- **战术行为**：寻找掩体、探头射击、交叉火力、包抄绕后、低血量撤退、呼叫支援。
- **阵营**：虚构武装分子（正规战术单位）与"失控学员"两类，行为模式不同。
- **难度自适应**：依据玩家表现动态调整压迫感（在"平衡成长"框架内）。

### 3.5 撤离系统
- 多个撤离点，各有开放条件（时间窗、激活装置、携带特定物）。
- 撤离倒计时与"最后呼叫"机制，制造高潮。
- 撤离点可能有守卫，需清场或潜行。

### 3.6 局外成长与经济系统
- 仓库、货币、商人/交易（买卖装备）。
- 任务线：引导目标，逐步解锁区域与高阶装备。
- 技能/体能成长：负重、恢复、潜行等缓慢提升。
- 成长节奏平滑，避免"碾压"或"卡死"。

### 3.7 存档与数据系统
- 本地存档（单机）：仓库、货币、任务进度、设置。
- 单局状态可断点续玩（可选）。

### 3.8 UI / HUD 系统
- 双端自适应 HUD：血量/部位状态、弹药、罗盘、任务、小地图（可选）。
- 背包、地图、改装、交易等界面。
- PC 键鼠与移动端触控两套交互布局。

## 4. 关卡场景

### 4.1 地图总览（单张中型战术地图）
- **名称（暂定）**：云杉学院（虚构）
- **规模**：约 0.5–1 km²，功能分区明确，动线可循环。
- **结构**：封闭学院区域 + 外围，含室内（战斗密集）与室外（潜行穿越）两类空间。

### 4.2 功能分区（建议）

| 区域 | 特征 | 玩法作用 |
|---|---|---|
| 教学楼群 | 多层走廊、教室、楼梯 | 室内近距离交火、vertical 战斗、丰富搜刮点 |
| 行政中心 | 办公室、档案室、监控室 | 高价值物资、任务目标、信息点 |
| 图书馆 | 大空间、书架掩体、楼梯 | 中距离交火、潜行路线 |
| 体育馆/操场 | 开阔空间、看台 | 远距离对狙、撤离中转 |
| 宿舍区 | 密集小房间 | 高风险近战、随机遭遇 |
| 实验楼 | 特殊房间、狭窄通道 | 稀有物资、紧张氛围 |
| 地下/管网 | 连接各区的通道 | 潜行绕行、侧翼包抄 |
| 外围道路与围墙 | 边界地带 | 撤离点分布、外围巡逻 AI |

### 4.3 撤离点设计
- 3–5 个撤离点，分布在不同方位，开放条件各异（如"东侧校门"定时开放、"地下车库"需激活电闸、"屋顶"需信号弹）。
- 至少一个"高风险高回报"撤离点。

### 4.4 敌人与物资分布
- 按区域设置 AI 密度与巡逻路线，热点区域高收益高风险。
- 物资刷新按稀有度分层，引导玩家向危险区推进。

## 5. 美术方向

### 5.1 整体风格
- **写实为主**：真实比例、材质质感、克制的光影，避免夸张卡通化。
- **氛围**：占领后的紧张、破败与秩序崩塌——散落的文件、翻倒的桌椅、临时工事、警示标识。
- **参考气质**：《暗区突围》的写实拟真与压迫感；**全部素材原创**，不使用其任何资产。

### 5.2 角色
- 主角汪义轩：成年高年级学员形象，着装写实（便装+自选护甲），可从慌乱到干练的外观成长。
- 敌人：虚构武装人员（战术装备）与失控学员两类， silhouette 清晰、辨识度高。

### 5.3 武器与道具
- 基于现实枪械逻辑设计但做原创化处理的虚拟型号，注重材质与机械细节。
- 道具、容器、UI 图标风格统一。

### 5.4 光影与后处理
- PC：中高画质——动态阴影、屏幕空间反射、体积光、景深、胶片颗粒。
- 移动端：中画质——烘焙/简化阴影、精简后处理、锁帧保稳。
- 统一色调：低饱和、冷色调为主，强调战术氛围。

### 5.5 音频方向
- 写实枪声（不同枪械/弹药差异）、脚步材质区分、环境音、心跳与呼吸（低血量）。
- 声音是玩法信息（AI 听声辨位），需与视觉反馈一致。

### 5.6 双端分级策略（"双端平衡"落地）

| 项 | PC（中高） | 移动端（中） |
|---|---|---|
| 分辨率/渲染 | 动态分辨率，最高 1440p | 720–1080p，锁定 30/60fps |
| 阴影 | 实时动态阴影 | 简化/烘焙阴影 |
| 材质 | 高精度 PBR | 降采样贴图 |
| 后处理 | 全套 | 精简（SSAO/色调映射） |
| 同屏 AI 数 | 较多 | 适度下调 |
| **共用** | 同一套玩法逻辑、地图、资产分级导出 | |

## 6. 操作流程

### 6.1 PC（键鼠）— 建议键位
- `WASD` 移动，`Shift` 冲刺，`C` 蹲伏，`Z` 趴下，`Space` 跳跃/翻越
- 鼠标左键射击、右键机瞄/倍镜，`R` 换弹，`T` 切换弹种
- `Tab` 背包，`M` 地图，`F` 互动/搜刮，`G` 投掷物，`1/2/3` 切枪
- `V` 第一/第三人称，`Esc` 暂停/设置

### 6.2 移动端（触控）— 建议布局
- 左侧虚拟摇杆移动，右侧滑动控制视角/瞄准
- 射击、蹲伏、跳跃、换弹、互动为可自定义悬浮按钮
- 背包/地图通过手势或固定图标打开
- 提供辅助瞄准（弱）、拾取自动拾取开关，兼顾操作精度

### 6.3 关键交互流程
- **搜刮**：靠近容器 → 按住互动 → 进度条 → 物品入包（产生声音）。
- **改装**：仓库/商人界面 → 选择武器 → 拖入配件 → 属性变化预览。
- **撤离**：到达撤离点 → 满足开放条件 → 进入倒计时 → 确认撤离 → 结算。
- **医疗**：受伤部位提示 → 选择对应医疗品 → 使用耗时动画 → 状态恢复。

## 7. 验收标准（Acceptance Criteria）

### 7.1 功能验收
- [ ] 可完成一整局：整备 → 进入地图 → 搜刮 → 交火 → 撤离 → 结算。
- [ ] 阵亡会按规则损失物资，撤离成功带回战利品。
- [ ] 弹道、护甲克制、部位伤害、后坐力均可被玩家感知并影响结果。
- [ ] 背包空间管理、改装、医疗系统可用且数值正确。
- [ ] AI 至少具备：视觉/听觉感知、掩体利用、包抄、撤退、呼叫支援。
- [ ] 至少 3 个具备不同开放条件的撤离点。
- [ ] 局外成长（仓库/交易/任务/技能）可运转，存档可读写。
- [ ] PC 与移动端均有完整可玩的操作流程。

### 7.2 性能验收
- PC：中高画质下主流配置稳定 60fps（1080p 参考）。
- 移动端：中画质、目标机型稳定 30–60fps，无严重发热降频。
- 单局加载时间可接受，场景切换无明显卡顿。

### 7.3 体验验收
- 单局时长落在 15–25 分钟区间。
- "平衡成长"：新手不会因连续死亡卡死，老手仍有挑战。
- 美术风格统一、写实，无与世界观冲突的元素。
- 双端核心体验一致，操作差异被合理吸收。

### 7.4 内容合规验收
- 全部人物、组织、场景原创且成年，不影射现实学校/事件。
- 玩法聚焦战术生存与突围，无针对现实的不当表达。
